# Release process

An unsigned development installer and portable artifact exist temporarily in GitHub Actions. No stable release version, signing key or GitHub Release exists. Before any release: select a version and licensing; run the test suite; maintain and independently validate Windows CI and reproducible packaging; perform Windows installation, upgrade, uninstall and functional acceptance testing; document dependencies; scan the output; produce SHA-256 checksums; verify code signing if configured or label binaries unsigned; prepare truthful notes; and publish only tested assets. Verify live download URLs and update the website. Do not publish dummy installers or claim tests that were not run.
