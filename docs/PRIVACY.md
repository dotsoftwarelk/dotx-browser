# Privacy

This prototype locally stores up to 1,000 visited page records (title and URL), bookmarks, search selection, and a persistent Qt WebEngine profile (which can include cookies, site data and cache). Addresses may contain personal or sensitive information. History can be cleared in the History dialog, but this does not remove cookies, cache, bookmarks or all website data. The experimental private window uses a separate off-the-record WebEngine profile, does not record DOTX history or bookmarks, and keeps its profile in memory. Downloads persist on disk. Websites, network operators and search engines can still observe activity, and private mode is not anonymity or a security audit. There is no full erase control, encryption guarantee or cloud synchronization.

Browsing sends data directly to sites visited. Search queries are sent to the selected search provider. Workspace buttons open provider websites, whose own privacy and login practices apply. Public GitHub repository searches send the query and network IP address to GitHub without authentication. Sign out on those sites; DOTX does not manage their connections or revoke provider credentials. The prototype implements no analytics, telemetry or Supabase backend; third-party sites may have their own telemetry.
