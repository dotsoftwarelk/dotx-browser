# Privacy

This prototype locally stores up to 1,000 visited page records (title and URL), bookmarks, search selection, optional restored-tab URLs, and a persistent Qt WebEngine profile (which can include cookies, site data and cache). Tab restoration is off by default; if enabled, up to 25 tab addresses (including query strings) are saved locally and are removed from settings when disabled. Addresses may contain personal or sensitive information. Bookmark exports are unencrypted local JSON files. Settings can disable future DOTX history recording; it is enabled by default. Turning it off does not erase existing history, session-only recently closed tabs, optional restored tabs, or WebEngine storage. History can be cleared in the History dialog, but this does not remove cookies, cache, bookmarks or all website data. Settings can request cookie and HTTP cache deletion, but other website storage can remain. The experimental private window uses a separate off-the-record WebEngine profile, does not record DOTX history or bookmarks, and keeps its profile in memory. Downloads persist on disk. Websites, network operators and search engines can still observe activity, and private mode is not anonymity or a security audit. There is no full erase control, encryption guarantee or cloud synchronization.

Browsing sends data directly to sites visited. Search queries are sent to the selected search provider. Workspace buttons open provider websites, whose own privacy and login practices apply. Public GitHub repository and issue searches send the query and network IP address to GitHub without authentication. The experimental GitHub account flow sends authorization requests and the `read:user` scope to GitHub when you choose Connect. Its token remains in process memory only, is not synced, and is cleared on local disconnect or exit. Local disconnect does not revoke GitHub authorization; revoke separately in GitHub settings. Other provider sessions are managed on their sites. The prototype implements no analytics, telemetry or Supabase backend; third-party sites may have their own telemetry.

The static website stores an optional appearance preference in local storage. Its download page retrieves public GitHub Actions metadata directly from GitHub; GitHub receives the visitor’s network address. The page degrades to a workflow link when metadata cannot be retrieved.
