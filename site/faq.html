FAQ

Answers about the current project.

Is there an installer?

Not yet. No verified Windows installer or release is available.

Are my services connected?

No. Workspace buttons are shortcuts to provider websites, not API connections.

Does it support private browsing or sync?

Neither feature is implemented. Local history and web profile data can persist.

Does the app require Supabase?

No. There is no Supabase backend in this prototype.

Will it run on my PC?

Windows compatibility and hardware performance have not yet been verified.
