DOTX / Documentation

Documentation

Get oriented with the current development prototype.

Setup

Install Python and the dependencies in requirements.txt, then run python -m dotx from the desktop directory. This is a development workflow, not a verified Windows installer.

Browser basics

Use the address bar to enter a web address or search. Open tabs with the plus button; drag tabs to reorder them. Use the star to bookmark a page. Right-click a tab to duplicate it or reopen a recently closed tab. The Tools menu offers keyboard shortcuts, find and zoom. The workspace buttons open provider websites. GitHub public search sends queries to GitHub without signing in.

Data and troubleshooting

History and bookmarks are stored locally. Browser engine data can also persist. If a site does not load, check your network and certificate settings; the prototype does not bypass certificate errors. Private windows are experimental; websites and network operators can still see activity, and downloads remain on disk. Advanced privacy controls are not yet available.

Updates and integration setup

No update system or native service authorization exists yet. Refer to the project source documentation for current limitations.
