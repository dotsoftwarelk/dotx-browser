DOTX / Features

Features

A practical foundation for a more focused browsing experience.

Available in the development prototype

Tabbed browsing with draggable and duplicate tabs, reopening recently closed tabs for the current session, address and search input, back, forward and reload, find in page and zoom controls. Save bookmarks, search and delete bookmark or history entries, select a search engine, and choose where to save downloads.

Workspace quick launch

Open Dropbox, Google Docs, Google Drive, Linear, Notion, GitHub and Supabase websites in new tabs. These are links only, not native API integrations or connected-account indicators.

Not yet implemented

Experimental private windows use an off-the-record profile and do not save DOTX history or bookmarks; downloads remain on disk. Session restore, advanced download management, permission settings, tab search, sync, account connections, updates and a complete accessibility review remain future work. See the documentation before use.
