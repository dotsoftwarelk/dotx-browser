Security

Transparent security information for a project in development.

Current status

DOTX is a development prototype and has not undergone an independent security audit. Do not use it for sensitive browsing until its security and permissions have been reviewed and tested.

Reporting

A dedicated security contact has not yet been configured. The project owner must publish a private reporting method before public release. Do not post secrets or exploit details publicly.

Release integrity

No signed or verified Windows release exists yet. Do not rely on unofficial installers.
