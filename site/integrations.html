Integrations

A starting point for accessing the tools you already use.

Current status: GitHub public repository and issue search uses the GitHub REST API without signing in. Other workspace destinations are website shortcuts. An experimental GitHub device sign-in requires an owner-registered app and has only been mock-tested. No account sync is implemented.

Dropbox

Open the official website from the workspace. Authentication and permissions are handled by that website. Native API access, connection status and setup are not yet implemented.

GitHub

Open the official website from the workspace. Search public repositories and issues through the GitHub REST API without signing in. Queries and your IP address are sent to GitHub and rate limits apply. An experimental device sign-in verifies identity when configured; it has not been tested with a real account. Private repository and issue access is not implemented.
