DOTX / Privacy

Privacy

Understand what the prototype stores and sends.

Local data

Browsing history, bookmarks and the search-engine selection are saved locally. If you enable tab restoration, page addresses are also stored locally and removed from settings when you turn it off. Bookmark JSON exports are unencrypted. Qt WebEngine may also store cookies, cache and other website data in its profile. Experimental private windows use a separate off-the-record profile and do not save DOTX history or bookmarks. Downloads remain on disk, and websites and network operators can still see activity. Complete clear-browsing-data controls are not yet available.

External services

Navigation and searches are sent to the websites and search provider you choose. Workspace links open third-party sites, which apply their own privacy policies. GitHub public searches send your query and IP address to GitHub. Experimental GitHub device sign-in sends authorization requests to GitHub; tokens stay in process memory and local disconnect does not revoke the grant. No DOTX cloud synchronization or persistent provider-token storage is implemented.

This website

The website stores your optional theme preference in browser local storage. The download page requests public build metadata directly from GitHub, which receives your network address. If GitHub is unavailable, the rest of the site still works.

Account disconnection

For GitHub, local disconnect removes the in-memory session but does not revoke the grant; revoke separately in GitHub settings. Sign out of other providers on their websites.
